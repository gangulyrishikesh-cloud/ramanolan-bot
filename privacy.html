Privacy policy

Effective 5 October 2026.

RamaNolan_bot is a personal assistant used only by its owner. Nobody else can sign in to it.

What it accesses

With the owner's consent, it reads the owner's Gmail and Google Calendar using read-only permissions (gmail.readonly, calendar.readonly). It cannot send, change, or delete email or calendar events.

How the data is used

Email and calendar content is read only to answer the owner's own requests, for example summarising unread mail or listing today's events. Answers are delivered to the owner over Telegram.

Where the data goes

Requests are processed on the owner's private server (hosted on Railway). To generate answers, the relevant content is sent to OpenAI's model API. Data is not sold, not used for advertising, and not shared with anyone else.

Storage

Access tokens are stored encrypted-at-rest on the owner's server with owner-only file permissions. The assistant keeps notes for the owner's convenience and is instructed not to store email content in them.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions.
